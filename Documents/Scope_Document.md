# 🗺️ Project Scope & Feature Checklist

## 🎯 Phase 1: Minimum Viable Product (MVP)
*Must be completed to have a working, playable game.*

### Player Systems
* [ ] **Player Controller:** 8-directional movement with acceleration. ( to be discussed)
* [ ] **Health System:** Take damage from hazards, die at 0 HP, respawn at checkpoint. ( to be discussed)
* [ ] **Combat:** Basic melee attack animation and hitbox detection. ( to be discussed)

### Enemy Systems
* [ ] **Basic AI:** Enemy patroller that moves between Point A and Point B. ( to be discussed)
* [ ] **Aggro State:** Enemy chases the player if they enter a detection zone. ( to be discussed)

### Core Systems
* [ ] **Game State Manager:** Main Menu -> Gameplay -> Game Over screen loop.
* [ ] **Level Layout:** 1 test level containing all core mechanics.
